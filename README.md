# BudžetBik 💰 - Vaš Osobni Financijski Asistent

## Opis Aplikacije

BudžetBik je napredna desktop aplikacija za upravljanje osobnim financijama, dizajnirana da vam pomogne pratiti, planirati i optimizirati vaše novčane tokove.

### 🌟 Ključne Značajke

#### 1. Praćenje Prihoda i Rashoda
- Jednostavan unos svih financijskih transakcija
- Detaljan pregled prihoda i troškova
- Kategorização transakcija
- Mogućnost dodavanja bilješki uz svaku transakciju

#### 2. Pametno Upravljanje Kategorijama
- Kreiranje prilagođenih kategorija troškova
- Postavljanje mjesečnih limita
- Praćenje potrošnje po kategorijama
- Upozorenja kod prekoračenja budžeta

#### 3. Fondovi za Štednju
- Kreiranje posebnih financijskih fondova
- Postavljanje ciljeva štednje
- Praćenje napretka
- Vizualni prikaz ušteda

#### 4. Pregledan Dashboard
- Grafički prikazi financija
- Mjesečni i godišnji izvještaji
- Brzi uvid u financijsko stanje
- Trend analiza potrošnje

### 🛠 Tehnički Detalji

#### Tehnologije
- Frontend: React
- Desktop Wrapper: Electron
- State Management: Zustand
- Styling: Tailwind CSS, MUI, Radix UI

#### Platforme
- Windows
- macOS
- Linux

### 🚀 Instalacija

#### Zahtjevi
- Node.js 16+
- npm 8+

#### Koraci Instalacije
```bash
# Kloniranje repozitorija
git clone https://github.com/Ja1Denis/winBik-app.git

# Ulazak u desktop direktorij
cd winBik-app/desktop

# Instalacija ovisnosti
npm install

# Pokretanje u development modu
npm run electron:dev

# Buildanje za produkciju
npm run electron:build
```
